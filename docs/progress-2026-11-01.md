## What was built on top of the 29 October checkpoint

1. **AppService** (`src/app/service.ts`): all 22 UI commands dispatch to the domain modules. Owner derived only from the server-side session guard; payloads are zod-strict; CAS conflicts return failure with fresh state; activity rows are written in the same atomic work; reply sends keep the pending-durable-before-provider-call ordering; `scheduledSync` honors the automation gate (default off) and the agent OAuth workflow.
2. **Storage**: `SheetRecordStore` opened from the `STORAGE_SPREADSHEET_ID` script property; `appsscript.json` carries the Sheets scope. Credentials stay in restricted script properties and never in Sheets, exports, browser state or logs.
3. **Calendar routing end-to-end**: a bounded post-sync reconcile stage (max 10 tasks/pass, oldest-first) reconciles open, reviewed tasks whose explicit decision is `automatic` with configured destinations — override → rule → account default. Review/ignore and imported-unreviewed tasks never write; conflicts are contained in a summary activity row; pages never reconcile (operations.md).
4. **UI**: item routing overrides (with true clear via nullable override), imported-draft review gate, imported-task badges, automation warning, storage/setup banners, sync-health display, route preview errors surfaced, rephrase proposal shown as a not-saved literal notice, disconnected accounts show no dead actions. Responsive layout, keyboard access, literal untrusted text preserved.
5. **Labelled local demo** (`npm run preview`): the real AppService + domain modules with simulated providers; one shared store per process demonstrates the phone/laptop continuity shape; reset/seed endpoints exist only under `ORBITDESK_DEMO_ALLOW_RESET=1` and the demo never bundles into the deployment.
6. **Hardening from reviews**: outbound host allowlist + portless-URL rule + CRLF-stripped headers + redirects off at the network sink; `login_hint` binding for OAuth; tolerant cleanup of corrupt pending/connection rows; demo CSRF guard; mkdtemp bundle directory.
